# 🌐 Estudos e Práticas em HTML5 & CSS3

Repositório dedicado ao armazenamento de exercícios, páginas web, estilizações e conceitos de Front-End desenvolvidos na **faculdade, cursos complementares e estudos autônomos**.

---

### 📂 Estrutura do Repositório

- **`/01-fundamentos-html`**: Estrutura semântica, tags de texto, links, formulários, tabelas e mídias.
- **`/02-estilizacao-css`**: Seletores, propriedades de texto, cores, bordas e *Box Model* (`margin`, `padding`, `border`).
- **`/03-layout-e-posicionamento`**: Alinhamento e estrutura de layout com **Flexbox**, **CSS Grid** e posicionamento (`relative`, `absolute`, `fixed`).
- **`/04-design-responsivo`**: Adaptação de páginas para dispositivos móveis usando *Media Queries* e unidades relativas (`rem`, `%`, `vh/vw`).
- **`/05-componentes-e-paginas`**: Páginas completas, formulários de login estilizados e cartões de exibição (*cards*).

---

### 🛠️ Tecnologias e Ferramentas

- **Linguagens:** HTML5, CSS3
